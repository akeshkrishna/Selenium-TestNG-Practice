# Selenium TestNG Practice Programs

## Overview
This repository contains Selenium WebDriver and TestNG practice programs created to understand and demonstrate core automation testing concepts using Java. The code focuses on hands-on learning of Selenium features and TestNG functionalities.

## Purpose
- To practice Selenium WebDriver concepts
- To understand TestNG annotations and test execution
- To improve automation scripting skills using Java
- To gain hands-on experience with web element interactions

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven
- Eclipse IDE

## Concepts Covered
- Browser Launching
- Webdriver Methods
- Navigation Command
- Locating web elements (ID, Name, XPath, CSS Selector)
- Web Element Methods
- Handling buttons, textboxes, radio buttons, checkboxes
- Webtable
- Dropdown handling
- Screenshot
- Alerts and pop-ups
- Drag and Drop
- Frames and windows
- Mouse and keyboard actions
- Scrolling operations
- File upload
- Wait mechanisms
- TestNG annotations and test execution
- Basic Page Object Model (POM) implementation
- SwagLabs practice scenarios
- Data-driven testing basics

## Note
This repository is intended for learning and practice purposes to strengthen automation testing fundamentals and is not a full-scale automation framework.
